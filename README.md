# Mochi 麻吉 · Windows 桌面宠物

一只会陪你、会提醒你的 Windows 桌面宠物 Mochi 安静地待在桌角，看你忙、看你摸鱼。
累了劝你喝口水，久坐了催你起身，还会陪你 AI 闲聊、按场景冒出心里话——但绝不弹窗打断你。

会看、会记、会陪你玩的 Windows 桌面搭子。一只透明无边框、常驻桌面的小宠物，
能感知你正在用什么软件、按时提醒你喝水/起身/番茄钟，还能陪你弹琴、被你摸头。

## ✨ 功能一览

- **6 位角色**，每位 9 种状态动画（Idle / Typing / Clicking / Happy / Sleepy /
  Excited / Petting / Peek / Reminding）
  - 团子猫 🐱 · 柴犬 🐶 · 抽象团 🫧 · 小欣 🌿 · 小甜 🍰 · 蓝羽少女 💙
- **3 步新手引导**：选角色 → 场景感知授权 → 完成（含快捷键说明）
- **设置面板**（侧边栏 5 类）
  - 通用：开机自启、音效、记忆、显示状态条、缩放
  - 角色：随时切换 / 循环切换
  - 提醒：喝水 / 起身 / 番茄钟 开关与间隔，提醒语气（温柔 / 中性 / 傲娇）
  - 场景：实时显示当前前台窗口与识别到的场景
  - 关于：陪伴天数、摸头次数等记忆统计 + 快捷键列表
- **提醒系统**：宠物举牌 + 气泡提示（**非系统弹窗**），可「好的 / 待会儿」
  类型：喝水 / 起身 / 番茄钟 / **上下班打卡**（自行设定上班、下班时间点，每天到点提醒打卡）
- **钢琴模式**（`Ctrl+Alt+P`）：WebAudio 实时合成，11 白键 + 7 黑键，宠物随节拍弹跳
- **场景感知**：读取前台窗口进程名 → 给出情境吐槽（编码 / 游戏 / 聊天 / 会议 /
  办公 / 影音 / 摸鱼）。读取脚本内嵌在程序里、启动时落到数据目录再交给 PowerShell 执行，
  不再依赖安装目录里的 .ps1（旧版打包后读 asar 路径失败，表现为「一直识别不到」）；
  设置页会实时显示当前识别到的进程；后台进程意外退出后 8 秒内自动重启
- **🌦️ 天气（和风天气）**：自己在设置里填城市（支持同名城市选择），按天气变化提醒——
  下雨带伞、下雪路滑、大风注意、高温补水、低温添衣、温差大加减衣服、紫外线强防晒、雾霾戴口罩。
  刷新间隔可设 **10/15/30/60/120 分钟**，同类提醒的重复间隔可设 **15/30/60/180 分钟**；
  **天气类型一变（比如刚开始下雨）会立刻提醒**，不等周期；提醒气泡后面附带实时摘要
  （温度 / 体感 / 风力 / 湿度），设置页还有**未来三天预报**。
  **凭据安全**：应用默认已内置开发者凭证（开箱即用，无需填写）。内置凭证在源码里只以
  AES-256-GCM 密文存在，密钥由散落口令碎片 + PBKDF2 派生，源码中无任何可读明文；首次启动
  立即用系统加密（Windows DPAPI，绑定当前账户）二次加密落盘，配置文件与磁盘均不含明文，
  且**界面绝不显示内置默认密钥**。设置里的「我的凭据」仅用于填你自己的和风凭证做覆盖，
  只有你自己填过的凭证才会在界面显示脱敏掩码；点「恢复默认」即可回退到内置凭证。
- **💬 AI 对话**（`Ctrl+Alt+A`）：默认用**内置免费接口，不需要填任何密钥**。独立对话窗口，支持多轮上下文、
  三种说话风格（温柔 / 简洁 / 毒舌）；可以让它帮你写台词、起名字、想提醒文案，回复时宠物也会在桌面上冒一句。
  **也支持换成你自己的 AI**：在「AI 对话 → 接口来源」里选「我自己的 AI」，填任意 OpenAI 兼容接口
  （OpenAI / DeepSeek / Moonshot / 本地 Ollama 等）的地址、模型名和 API Key 即可，Key 同样用系统加密
  只存在你本机；不填或不切换就继续用内置免费接口，点「恢复默认接口」随时切回
- **❓ 帮助页**：设置里内置完整使用手册——**一键「重新看一遍」新手引导**（走的是首次那套 3 步流程，
  不会覆盖已有设置）、快速上手 5 步、快捷键表、常见问题排查
- **📮 用户反馈**：设置里直接填写建议/问题，提交后**自动发到作者邮箱**；提交过程用居中弹窗反馈状态
  （发送中 / 成功 / 失败一目了然），失败会本地留档并支持一键复制内容
- **托盘菜单 + 全局快捷键**（`Ctrl+Alt+S` 设置 / `Ctrl+Alt+A` AI / `Ctrl+Alt+R` 找回 / `Ctrl+Alt+C` 切换角色 / `Ctrl+Alt+P` 钢琴）
- **养成数值**：心情 / 精力 / 亲密度（**默认不常显**，鼠标移到宠物身上才出现，可在设置里改回常显），本地记忆（陪伴天数、摸头次数）
- **🎨 台词自定义**：每一位角色的全部口头禅（日常 / 戳一戳 / 打招呼 / 提醒）与
  场景吐槽（编码 / 游戏 / 聊天 / 会议 / 办公 / 影音 / 摸鱼）都可单独编辑，立即生效
- **🖼️ 自定义形象**：点「选择图片」调起系统文件选择器（png / jpg / jpeg / webp / gif / bmp），
  创建专属角色——9 种状态可分别指定图片（也可一键用主图填充），选中后会显示文件名并自动
  复制到数据目录（原图删除也不受影响）；配套英文名 / 性格标签 / 招牌台词 / 配色，可在设置里
  随时编辑或删除，引导页也会同步显示
- **🚶 走动可控 + 随意拖动**：**自由走动默认关闭**——不开就一直待在原地不动；
  打开后只在你**当前那块屏幕的可用区域内**小步走动（不主动跨屏、不压任务栏）；
  按住它拖到任意位置，松手即停，松手时只要有一点超出可用区就立刻收边
- **🔎 永远丢不了**：每 4 秒巡检一次，窗口四边只要有一处超出桌面可用区（含被任务栏遮住），
  就地收回视野内；也随时可以点托盘「把宠物叫回眼前」或 `Ctrl+Alt+R` 喊回来
- **🎭 图标随角色变化**：切换角色后，**窗口图标与托盘图标立刻变成该角色的形象**（正方形裁切、透明留白均匀）
- **🪟 窗口层级（三档）**：置顶显示 / 半透明置顶（可见且能透视被压住的窗口）/ 桌面层（退到普通窗口之下，可见但不遮挡内容）
- **💾 数据保存位置可自定义**：默认位于 C 盘 `AppData/Mochi`，可在设置里改到任意磁盘，**改完立即生效、重启也记得**
- **✍️ 内置角色可自定义**：任意内置角色都能改名字 / 英文名 / 口头禅 / 性格标签 / 各状态与各场景台词，可一键恢复默认
  （配置与自定义形象图片会一并迁移，并自动修正图片路径）

## 📁 项目结构

```
Mochi/
├─ main.js                主进程：窗口 / 托盘 / IPC / 场景监听 / 提醒调度 / 数值
├─ preload.js             渲染进程安全桥接（contextBridge，不暴露 Node）
├─ build.mjs              构建辅助（解决中文路径导致的 rcedit 失败）
├─ package.json
├─ assets/                透明化后的角色素材（每角色 9 状态 PNG，由脚本生成）
│  └─ <char>/state.png
├─ build/                 图标(icon.ico/tray.png)、manifest.json、自检截图
├─ scripts/
│  ├─ prepare_assets.py   白底素材 → 透明 PNG + 统一裁切 + 图标生成
│  └─ active-window.ps1   场景感知：前台窗口进程名/标题（仅作参考，运行时不读这里——已内嵌进 main.js 并落到数据目录）
└─ src/
   ├─ shared/
   │  ├─ dialogues.js     角色数据 / 场景规则 / 提醒文案 / 状态列表
   │  ├─ sound.js         WebAudio 合成（chirp/purr/bell/piano）
   │  └─ theme.css        共享设计系统（标题栏 / 卡片 / 开关 / 按钮）
   ├─ pet/                宠物透明覆盖窗口（状态机 / 气泡 / 拖拽 / 摸头）
   ├─ onboarding/         3 步引导
   ├─ settings/           设置面板
   └─ piano/              钢琴模式
```

## 🚀 运行（开发模式）

```bash
# 1. 安装依赖（首次）
npm install

# 2. 准备素材（白底源图 → 透明 PNG；已生成过可跳过）
npm run prepare-assets

# 3. 启动
npm start          # 普通启动
npm run dev        # 带 --dev 标记启动
```

> 启动后首次会进入新手引导；完成后宠物常驻桌面右下角附近。
> 想再走一遍引导：设置 →「帮助」→ 新手引导卡片上的「重新看一遍」。
> 右键托盘图标可打开设置 / 钢琴 / 退出。

### 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Alt+P` | 打开 / 关闭钢琴 |
| `Ctrl+Alt+C` | 打开设置 |
| `Ctrl+Alt+S` | 截图自检（开发用，生成 `build/shots/*.png`） |

### 宠物交互

- **拖拽**：按住宠物移动位置
- **单击**：戳一下（poke），宠物做出反应
- **悬停**：抚摸（petting），累计摸头次数
- **Ctrl + 滚轮**：缩放宠物大小

## 🎨 自定义台词与形象

这两项均在 **设置 → 角色** 页操作（右键托盘 → 设置，或 `Ctrl+Alt+C`）。

### 编辑角色台词（口头禅）

每个角色卡片上的 **「编辑台词」** 按钮打开台词编辑器，可修改：

- **日常台词**：闲置时随机冒出的口头禅
- **戳一戳 / 打招呼** 的回应文案
- **提醒台词**：宠物举牌提醒时的语气文案
- **场景吐槽**：根据当前前台窗口（编码 / 游戏 / 聊天 / 会议 / 办公 / 影音 / 摸鱼）
  实时吐槽的文案

修改即时保存（写入 `%APPDATA%/Mochi/mochi-config.json` 的 `charDialogues`），
无需重启；改空某条则回到该角色的默认台词。

### 添加 / 编辑 / 删除自定义形象

点击 **「＋ 添加自定义形象」** 创建专属宠物：

1. 填写名称、英文名、性格标签、招牌台词、配色；
2. 为 **9 种状态**（Idle / Typing / Clicking / Happy / Sleepy / Excited /
   Petting / Peek / Reminding）分别 **选择图片**（本地图片）；
3. **至少要传一张**（建议放在「待机」）。只传其它状态时，会自动把第一张提升为待机图，
   不然桌面上取不到待机图就会退回内置形象，看上去像"没生效"；
4. 未指定的状态会自动沿用待机图，保证宠物始终有画面；
5. 保存后**已经保存的形象会排在最前**（自己做的优先），并**自动切换到它**，
   桌面上立刻就能看到；新卡片会短暂高亮，方便在列表里找到。

自定义形象保存在用户数据目录 `Mochi/custom/<id>/`，图片以 `file://` 形式引用；
自定义角色可随时 **编辑** 或 **删除**（删除后若正使用该角色会自动回退到团子猫）。

**找不到 / 不显示时怎么排查**：

- 卡片上有红色 **「缺图片」** 角标 → 这个形象没有可用图片（多是旧版本上传功能失效时
  建的空壳），点 **「上传图片」** 补一张即可；点卡片本身也会弹出补图提示
- 图片文件被删了 / 换过保存位置 → 启动时会自动清理失效条目，宠物回退到内置形象而**不会变空白**
- 换了新形象但桌面没变 → 确认打开的确实是新版（托盘右键退出旧进程再启动）

> 提示：自定义形象的图片建议使用透明背景 PNG；状态图尺寸无需严格一致，
> 运行时按比例缩放展示。

## 📦 打包发布

> ⚠️ **中文路径问题**：本项目目录含中文，electron-builder 的 `rcedit`
> 无法写入含非 ASCII 字符的输出路径而报错。请用下方脚本，它会把产物
> 输出到系统临时目录（纯 ASCII 路径）以绕开该问题。

```bash
# 生成可直接运行的目录 + 目录压缩包（推荐先验证）
npm run pack
#   → dist/Mochi/Mochi.exe 与 dist/Mochi-Folder.zip

# 生成 NSIS 安装包
npm run build
#   → dist/Mochi-Setup-1.0.0.exe

# 生成单文件便携版
npm run build:portable
#   → dist/Mochi-Standalone.exe
```

> 脚本默认先把产物构建到纯 ASCII 的临时目录再回填 `dist/`，以绕开中文路径 rcedit 报错；
> 构建末尾会自动校验并修正 exe 图标（`scripts/fix_exe_icon.py`），确保 7 帧图标正确写入。
> 最后一步是**代码签名**（`scripts/sign.mjs`）：默认用自签占位证书给所有 exe 加上 Authenticode 签名 + 时间戳。
> 自签不能消除别人电脑上的 SmartScreen「未知发布者」警告，要正式签名请设 `CERT_PFX` / `CERT_PASSWORD`
> （或在 CI 配 Azure Trusted Signing），详见 [`docs/RELEASING.md`](docs/RELEASING.md) 第 4 节；
> 不想签名就 `set SIGN=0`。

### 三种分发方式（按"打开速度 / 是否单文件"取舍）

| 产物 | 说明 | 启动速度 | 适合场景 |
| --- | --- | --- | --- |
| **`Mochi-Setup-1.0.0.exe`** | NSIS 安装包（约 81MB，已内嵌图标）。装一次，开始菜单/桌面出现快捷键 | **最快（≈2s）** | 自己电脑长期用、追求秒开 |
| **`Mochi-Folder.zip`** | 整个可运行目录压缩包（约 114MB）。**一个文件发给别人**，对方解压一次后双击 `Mochi.exe` | **快（≈2s）** | 发给别人、又想秒开 |
| **`Mochi-Standalone.exe`** | 真正的单个自解压 exe（约 77MB，已内嵌图标）。零安装，双击即用 | 慢（≈9s，每次自解压） | 只发一个 exe、对方不想解压/安装 |

> ⚠️ 单文件版为什么慢：Electron 无法"裸 exe 单跑"，`Mochi-Standalone.exe` 每次启动都要把约 180MB 运行时解压到临时目录（实测自解压约 9 秒）。
> 想要**秒开的单文件体验**，请用上面的 zip（解压一次）或安装版；它们启动实测约 0.2s 出进程。
> 若一定坚持"单个 exe 且要快"，可另打一个**不压缩版单文件**（约 180MB，启动 2–3s），代价是文件较大。

### 窗口层级（三档）行为说明

设置 → 常规 → 窗口层级：
- **置顶显示**（默认）：始终浮在最前，鼠标可穿透（不挡点击），但会盖住其下窗口的视觉内容。
- **半透明置顶**：仍置顶并始终可见，但整体 45% 透明——**隔着它也能看清被压住的窗口内容**，兼顾"看得到"和"不遮挡"。
- **桌面层**：宠物退到普通窗口层级（不再置顶）。**在桌面或未被应用遮挡处依然可见**，被你正在用的软件盖上，不挡信息。
  （早期版本误用 `lower()` 把窗口压到桌面窗口之下，导致彻底看不见；现已改为 `setAlwaysOnTop(false)`，三档均已实测 `visible=true`。）


> 若想从源码目录直接 `electron-builder --dir` 且路径无中文，可忽略上述脚本。
> 把整个 `Mochi` 文件夹复制到一个纯英文路径（如 `C:\mochi`）再构建亦可。

## ⚙️ 配置与记忆

配置与本地记忆保存在用户数据目录（默认）：

```
%APPDATA%/Mochi/mochi-config.json
```

包含：当前角色、场景感知开关、提醒设置、通用偏好、窗口层级、陪伴天数、摸头次数等。
删除该文件即恢复首次启动（重新走引导）。

### 💾 把数据保存到非 C 盘

默认数据在 C 盘 `AppData`。若想改到 D 盘等任意位置：

1. 打开 **设置 → 常规 → 数据保存位置**；
2. 点 **「更改保存位置…」** 选择一个文件夹（如 `D:\MochiData`）；
3. 应用会把配置与自定义形象图片复制到新位置、修正图片路径，并**立即切换（无需重启）**；下次启动也自动记住。

迁移记录写在标记文件 `<exe 稳定目录>/mochi-path.txt` 里（仅一行路径）。
单文件版会写到 `PORTABLE_EXECUTABLE_DIR`（exe 实际所在目录），因此不会因临时解压目录变化而失效。
想回到默认 C 盘，点 **「恢复默认」** 即可。

> 也可以用命令行 `--user-data-dir=路径` 启动，效果相同。

## 🔧 素材预处理说明

源素材为 `2048×2048` 白底 RGB PNG（每角色 9 状态）。`scripts/prepare_assets.py`
会：

1. OpenCV `connectedComponents` 识别四边连通的背景并抠成透明；
2. 近背景中性像素裁切 + `cv2.inpaint`（TELEA）修复白边渗出；
3. 形态学开运算去除投影碎屑；
4. 统一缩放到 `512×512` 并做**每角色统一裁切框**（保证 6 角色构图一致）；
5. 生成 `build/icon.ico` / `build/tray.png` / `build/icon.png` 与 `assets/manifest.json`
   （含每角色裁切框与 `visualRatio` 用于前端高度归一化）。

依赖：`opencv-python-headless`、`numpy`、`pillow`。
